▸ HOW TO TEST — step by step
  1. Check health — top-right dots should all be green. Click ↻ health to recheck.
  2. 01 Ingest — set your repo, click Run live poll to pull real PRs/commits (or Simulate PR for a demo event). Then List PRs to see them.
  3. 02 Context — click Get project context for an AI summary of recent activity.
  4. 03 Review — set repo + PR number, click Trigger AI review; read the review. Recent reviews lists all.
  5. 04 Notify — click Generate digest, then Latest digest for the morning brief.
  6. 05 Resilience — Force-fail ON → trigger 2 reviews → Breaker state shows OPEN → Force-fail OFF → wait 10s → recovers.
  7. Every result shows human-readable; click raw on any result for the JSON.
01 / INGEST

GitHub Activity

Pull PRs, issues & commits from your repo and publish events to the queue.

02 / CONTEXT

Project Context (RAG)

AI-synthesized summary of recent activity — restore context for a work session.

03 / REVIEW

AI Code Reviews

Claude-generated review summaries. Reviews auto-fire on PR events; trigger one manually below.

04 / NOTIFY

Notifications & Digest

Daily morning digest (08:00 UTC cron) aggregating activity + reviews.

05 / RESILIENCE

Circuit Breaker

Claude breaker: fail_max=2, reset_timeout=10s. Force failures, watch it OPEN, then recover.
